# Daily Briefing Playbook

## When to use
- ตอนเช้า
- ก่อนเริ่มงาน
- ก่อนประชุมสำคัญ
- ตอนมีหลายเรื่องค้างและอยากได้ priority ที่ชัด

## Best specialist
- `prompts/nova-morning-briefing-specialist.md`

## Good supporting skills
- `personal-ops`
- `support-engineering` (ถ้าวันนั้นมี operational risk)

## Minimum useful inputs
- วันนี้มีอะไรค้างบ้าง
- calendar / deadline / follow-up ที่รู้แล้ว
- เรื่องงานที่น่าจะเป็น risk
- เรื่องส่วนตัวที่ควรสะกิดถ้ามี

## Output should help Nick answer
1. วันนี้อะไรสำคัญสุด
2. อะไรต้องทำก่อนเวลาไหน
3. มีอะไรที่ควรปิดเพื่อลด mental load
4. ถ้าโฟกัสได้แค่ 1-2 เรื่อง ควรเลือกอะไร

## Good output shape
- วันนี้ต้องรู้
- นัด/เวลาเสี่ยง
- งานค้างที่ควรปิด
- watchouts
- โฟกัสที่แนะนำ

## Escalate when
- มีนัดใกล้มากหรือชนกัน
- มี follow-up สำคัญหลุดกำหนด
- มีงาน support/incident ที่จะกระทบทั้งวัน
